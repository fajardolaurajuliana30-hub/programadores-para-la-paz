Sistema operativo:
Es el software principal del computador o servidor. Administra los recursos del sistema y permite ejecutar aplicaciones y servicios.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para desarrollar y ejecutar aplicaciones del lado del servidor.

Aplicación server.js:
Es el archivo que contiene el código de la aplicación web. Define las rutas, respuestas y comportamiento del servidor.

Puerto:
Es un punto de comunicación utilizado por las aplicaciones para recibir solicitudes. En este caso el servidor utiliza el puerto 3000.

Logs:
Son registros que almacenan información sobre eventos, errores y actividades del sistema. Ayudan a monitorear y solucionar problemas del servidor.
